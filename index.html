AI Benchmarks

A practical toolkit for evaluating LLM-based systems — prompts, agents, and pipelines. For teams that already ship with LLMs and need a repeatable way to catch regressions.

The problem

Vibes don't scale

A single mega-prompt that "feels right" in a demo and a slow manual human-review loop are the two most common eval strategies — and neither one catches regressions before your users do.

One mega-prompt isn't a test suite

A single hand-tuned prompt that "feels right" in a demo tells you nothing about the hundred edge cases your users will actually hit. Vibes don't regress-test.

Vibes-based testing hides regressions

Eyeballing outputs after every change catches the failures you already expect and misses the ones you don't. By the time a regression is visible, it's already shipped.

Manual human review doesn't scale

A human reading every output works for a demo and breaks the moment you ship weekly. You need automated signal on every commit, with human judgment reserved for calibration — not gatekeeping.

Try it

A runnable example

A minimal rubric-scoring harness in plain Node — zero dependencies, no framework lock-in. Fork it and swap in your own pipeline's output.

// Each rubric item is a weighted, independently checkable claim about the output.
const checkers = {
  contains:   (output, { value }) => output.toLowerCase().includes(value.toLowerCase()),
  not_contains: (output, { value }) => !output.toLowerCase().includes(value.toLowerCase()),
  valid_json: (output) => { try { JSON.parse(output); return true; } catch { return false; } },
  max_sentences: (output, { value }) => (output.match(/[.!?]+(\s|$)/g) || []).length <= value,
  // llm_judge delegates to a real model call — gated behind an API key
  // so the harness runs with zero setup and fails loud without one.
};

function scoreCase(testCase) {
  const results = testCase.rubric.map((item) => ({
    ...item,
    passed: checkers[item.type](testCase.output, item),
  }));
  const total  = results.reduce((sum, r) => sum + r.weight, 0);
  const earned = results.reduce((sum, r) => sum + (r.passed ? r.weight : 0), 0);
  return { ...testCase, results, score: earned / total };
}

// node harness.js --threshold=0.8
// exits non-zero when the average score regresses below threshold — wire
// that into CI to gate merges on eval score, not on someone remembering to look.
